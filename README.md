# Inset

Plan replacement cushions for indoor and outdoor furniture. Explore twelve original sample fabrics, keep saved looks and measurements together, and see a planning price range. Final price from your quote. Ordering, payment and swatch delivery are not available.

Connect your Inset workspace, then upload furniture privately at https://shopinset.com. Photos are stored on Cloudflare and processed by OpenAI for furniture observations, starting size guesses and fabric previews. A project can hold six photos with separate furniture counts and looks. Starting sizes stay unconfirmed until you check them with a tape. See a typical-size range first, then refine it with your measurements. This connection cannot read chat attachments or chat history. Guest projects stay in their browser for seven days; email sign-in lets you return across devices.

Generate new previews on the website, then return to your conversation to compare saved looks.

Try:

- My patio cushions are faded. Help me pick fabrics and measure for new ones.
- Compare the saved fabric looks on my indoor bench.
- Check my cushion measurements and show an estimated price range.

## Reviewer walkthrough

A dedicated reviewer workspace is available. Follow the login instructions and use the credentials supplied in the private submission portal fields. No email code is needed. Open https://shopinset.com/reviewer to sign in. Credentials are never included in this package.

Open the project named Reviewer patio chair. It contains a furniture photo, saved fabric looks, confirmed example measurements and a planning estimate. Read the project, compare its saved looks, check its measurements and request a fresh estimate. The example dimensions are not inferred from the photo. Use a separate project when testing missing measurements or deletion.

Connect Inset from the same browser workspace used for reviewer sign-in. For a new preview, open the project website and choose a fabric there, then return to the conversation to read the saved result.

## Tool annotations

`select_design`, `update_specification` and `delete_photo` have `destructiveHint: true` because they replace saved choices or delete a photo. Read-only tools cannot change projects. Preview generation and commerce tools are not available through this Claude connection.
